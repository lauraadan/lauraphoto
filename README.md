# Portfolio de Fotografía — React

Portfolio editorial, responsive y moderno construido con React + Vite.

## Requisitos
- Node.js 20+ recomendado
- npm

## Instalación

```bash
npm install
npm run dev
```

Abre la URL que indique Vite (normalmente `http://localhost:5173`).

## Producción

```bash
npm run build
npm run preview
```

## Personalización

La galería está definida en `src/main.jsx`, dentro de `photos`.
Sustituye las URLs de Unsplash por tus fotografías.

También puedes cambiar:
- Nombre y textos de portada
- Categorías
- Email e Instagram
- Colores en `src/styles.css`
- Tipografías en `index.html`

El diseño no necesita backend y funciona como SPA estática.
